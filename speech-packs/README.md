# Speech-Packs

To enable audio station announcements you will need a micro-sd card, formatted as FAT32 with the two speech-packs installed.

Copy the two folders <b>V1</b> and <b>V2</b> to the root of the micro-sd card, retaining the precise file and folder structure here.

You can also create your own speech-packs (e.g. V3, V4 etc.) by creating your own speech files.
